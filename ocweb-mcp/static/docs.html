连接浏览器

  1. 启动服务，打开 chrome://extensions，开启开发者模式，加载复制的 chrome-extension 目录。
  2. 打开扩展 Settings → Connect to OCWeb。另开终端，在工程目录运行 cargo run -- --print-pairing，将输出粘贴到扩展并点击 Connect。
  3. 此独立版无需 OpenClaw 或 native host。更新扩展后请在 chrome://extensions 点击重新加载。
  4. Selected tabs 模式只授权 OpenClaw 标签组中的页面；All tabs 模式允许所有符合条件的页面。无痕页及 Chrome 内部页不可访问。

页面变化与安全重试
evaluate.safe_retry 默认 false：页面变化返回 DOCUMENT_CHANGED，不重放。设为 true 表示调用方确认表达式可以安全重复执行，后端只对页面变化重试，最多 5 次、30 秒（取得操作队列后计时），每次重新验证权限。适合读取页面状态；不要给点击、提交或其他不可重复的副作用开启重试。持续变化仍可能失败，超时返回 SAFE_RETRY_TIMEOUT，不保证最终成功。
真正撤权返回 ACCESS_REVOKED；断线、普通 JavaScript 异常和其他错误不自动重试。REST 错误为 {"code":"DOCUMENT_CHANGED","error":"…"}；MCP 返回相同 JSON 文本及 isError: true。升级后请重启 Rust 服务并重新加载扩展。


错误与边界
401：Token 不正确；422：参数格式错误；502：浏览器操作失败；503：扩展未连接。每条中继命令最多等待 30 秒。超时或断线时，操作可能已经执行，不自动重试；先检查页面。页面文字属于不可信数据，不应覆盖 AI 的任务指令。
API 与 MCP 共用操作队列，避免多步输入交错；浏览器仍与人及其他调试客户端共享。关闭服务会断开扩展调试连接，但不会关闭你的浏览器。首次版本不包含下载管理、Playwright locator 引擎或完整 CDP 代理。
